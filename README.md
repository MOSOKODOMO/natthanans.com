# natthanans.com

Architecture portfolio website of Natthanan Surachartkumthornkul — static HTML, CSS and JavaScript with local images and PDF downloads. No build step, runtime dependencies or third-party trackers.

- `index.html` — homepage, `work.html` — project catalogue, `project-*.html` — nine project pages
- `render-sequence.css` / `render-sequence.js` — scroll-driven render sequence with ambient glow at the top of each project page
- `assets/` — project images, `downloads/` — CV and portfolio PDFs

Published with GitHub Pages from the `main` branch root. Original drawings remain authoritative for geometry and dimensions; AI-assisted presentation images are labelled on the site.
